# 欢迎使用 TyporaX

这是你的免费 Markdown 写作空间，内容保存在本机。

## 开始写作

在新的一行输入 `## ` 创建标题，输入 `- ` 创建列表。用 **⌘S** 保存，用 **⌘/** 切换源码。

- [x] 本地 Markdown 文件
- [x] 可视化与源码编辑
- [ ] 写下今天的第一个想法

## 公式与图表

行内公式：$E = mc^2$。

```mermaid
flowchart LR
  A[一个想法] --> B[一段文字]
```

| 操作 | 快捷键 |
| --- | --- |
| 打开 | ⌘O |
| 保存 | ⌘S |
| 查找与替换 | ⌘F |

> 写作时请定期保存文件。本地草稿会恢复，但不会代替你写入原文件。
