## 功能覆盖

浏览器用例覆盖 Markdown 输入和工具栏、表格、代码语言、链接、公式、Mermaid、图片、源码往返、特殊语法保护、查找替换（含中文及 Unicode 偏移）、主题、专注/打字机模式、工作区列表与大纲、草稿恢复、外部修改冲突、保存取消及多文档撤销隔离。其中涉及原生宿主的浏览器用例使用模拟桥接，验证界面行为与消息参数。

另外的 12 组原生集成用例启动真实 AppKit/WKWebView，验证 Finder 打开与初始化时序、DOM 编辑和工具栏操作、精确源码保存、另存为/取消、工作区读写授权、图片嵌入与目录范围、HTML/PDF 磁盘产物、外部修改保护、关闭取消和保存全部。测试在独立偏好、非持久 WebKit 会话和临时目录中运行，结束后清理，避免接触使用者的草稿和文件。

原生集成测试只注入系统文件选择框及关闭提示框的选择结果；编辑器、消息桥接、磁盘操作、PDF 和窗口关闭实际执行。桌面自动化读取 TyporaX 和 Finder 均超时，因此没有把系统对话框的实际鼠标点击、实体键盘或输入法交互计为通过。

尚未验证：Intel 真机、其他 macOS 版本、中文输入法候选词交互、复杂长文混合图表的打印布局。GitHub Actions 的结果以对应提交的远程运行记录为准。
