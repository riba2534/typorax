# TyporaX 1.0.0

免费、开源、离线可用的 macOS Markdown 编辑器。支持可视化与源码编辑、表格、待办、公式、Mermaid、文件夹工作区、草稿恢复、HTML 和分页 PDF。

## 安装

下载本页的 arm64 DMG，打开后将 TyporaX 拖入 Applications。需要 macOS 14+ 和 Apple Silicon（M 系列）Mac，运行不需要 Node.js。

SHA256SUMS 可用于核对下载内容。应用采用 ad-hoc 签名，尚未经过 Apple Developer ID 公证。

## 验证与范围

安装包只在浏览器功能回归、原生文件与 WKWebView 集成、PDF 和签名/DMG 校验通过后发布。详见仓库中的 docs/validation.md。

前置元数据、脚注和原生 HTML 等语法当前保留在源码模式。尚无云同步、插件、多窗口或 DOCX 导出；完整范围见 docs/compatibility.md。
