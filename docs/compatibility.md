# 格式与平台兼容性

## 平台

桌面应用最低 macOS 14。发行安装包面向 Apple Silicon；构建脚本支持 Intel，但不能把交叉编译成功视作 Intel 真机验收。Node.js 仅在开发构建时使用。

## Markdown

可视化模式支持标题、段落、粗体、斜体、删除线、引用、列表、待办、链接、图片、表格、代码块、行内及块级公式。Mermaid 通过代码块预览。

只打开文档或切换模式不会自动保存或重写原文。可视化编辑后会规范化 Markdown 的空行、列表符号等格式。精确保留源码排版时应使用源码模式。

含前置元数据、脚注、原生 HTML、引用式链接或检测到的扩展块语法时，保留在源码模式。它们的 HTML/PDF 导出当前以原始文本呈现。该保护并不代表支持所有 Markdown 方言。

表格列宽是编辑界面的显示属性，Markdown 不持久保存列宽。撤销/重做在当前编辑会话内工作；切换文档或编辑模式会重置视图历史，当前没有每篇文档持久的撤销栈。

## 文件与图片

- 文档使用 UTF-8，读取与保存上限 32 MiB；超限时拒绝写入，保留磁盘原文件。
- 新插入的 PNG/JPEG/GIF/WebP/BMP 图片以 Data URI 嵌入文档，单张上限 20 MiB。大图会显著增加 Markdown 体积。
- 相对路径图片仅允许位于当前文档目录及其子目录；不跟随越过授权范围的符号链接。远程图片需要网络。
- 文件夹扫描跳过隐藏目录、软件包、符号链接及 node_modules/dist/build/vendor，最多检查 20,000 个条目，显示 2,000 个文档。
- 本地草稿受 WebKit 存储空间限制。它用于意外中断后的恢复，正常保存仍需 ⌘S。
- 写入已有文件前会与本次读取的磁盘内容比较；冲突时保留外部改动，要求另存或重新打开。

## 导出

HTML 包含独立排版及公式样式，Mermaid 转为 SVG，可读取的相对图片会内嵌。远程图片保持远程地址。

PDF 使用系统 WebKit 与 CoreGraphics 生成 A4 页面，优先按段落或块边界分页。超高代码块、表格或图表可能跨页。导出最多处理 200,000 CSS 像素高度，超时上限 30 秒；复杂长文应检查分页效果。

## 产品范围

目前没有多窗口、插件、自定义主题编辑器、历史版本、同步服务、DOCX/Pandoc 转换或自动更新。更新应用时下载新版本替换即可，Markdown 文件由用户自行管理。
